1. What is a React component?
    It is a function - that returns react elements which are the building block of the react web-page interpreted as html

2. What's wrong with this code?
```
function myComponent() {
    return (
        <small>I'm tiny text!</small>
    )
}
```
    It's not in PascalCase, may be the div name is odd
    
3. What's wrong with this code?
```
function Header() {
    return (
        <header>
            <img src="./react-logo.png" width="40px" alt="React logo" />
        </header>
    )
}

root.render(Header())

```
    everything is fine, the element could have been called differently:
    root.render(<Header />)
