1. What does the `.map()` array method do?

- it takes an initial array and then uses a function on each value, then populates the new array with corresponding values in the indeces



2. What do we usually use `.map()` for in React?

- to create arrays of repetative react jsx components based of some other file format of the source data


3. Critical thinking: why is using `.map()` better than just
   creating the components manually by typing them out?

- because it maps all the elements of the array automatically, it would take forever to map everything out with the bigger source. 
- It is also a reusable method to do other things, rather than making something for that one purpose only.
